# DashTron Gate — รหัสดาวน์โหลดใช้ครั้งเดียว (Telegram Bot + Web)

```
แอดมิน ──/gen ST7789──▶ Telegram Bot ──▶ ได้รหัส 6NZ2-PW95-WZ7D
                                              │ ส่งให้ลูกค้า
ลูกค้า ──กรอกรหัสที่เว็บ──▶ Server ตรวจรหัส ──▶ ปล่อยไฟล์ .bin (ผ่าน token ชั่วคราว 30 นาที)
        ติดตั้งสำเร็จ ──▶ /api/complete ──▶ รหัสถูกเผา ใช้ซ้ำไม่ได้ + บอทแจ้งแอดมิน
```

## ติดตั้ง (ต้องมี Node.js 18+ — ไม่ต้อง npm install)

1. `@BotFather` → `/revoke` สร้าง token **ใหม่** (token เก่าที่เคยส่งในแชทถือว่ารั่วแล้ว)
2. `cp .env.example .env` แล้วใส่ `TELEGRAM_BOT_TOKEN`
3. `node server.js` → ส่ง `/start` หาบอทเพื่อดู Telegram ID ของคุณ → ใส่ใน `ADMIN_IDS` → รันใหม่
4. `npm run sync-firmware` ดึง .bin จาก GitHub มาเก็บในโฟลเดอร์ `firmware/` ของเซิร์ฟเวอร์ (ตรวจ sha256)
5. **ตั้ง repo GitHub เป็น Private** (ไม่งั้นใครก็โหลดจาก raw.githubusercontent.com ได้โดยไม่ต้องใช้รหัส) — ถ้า private ให้ตั้ง `FIRMWARE_GITHUB_TOKEN` ตอน sync
6. วางหลัง HTTPS (nginx/Caddy/Cloudflare) เพราะ Web Serial ต้องใช้ https · ตั้ง `TRUST_PROXY=1`

> เซิร์ฟเวอร์ต้องเป็นเครื่องที่รันตลอด (VPS / Railway / Render ฯลฯ) — โฮสต์สถิตแบบ GitHub Pages ใช้ไม่ได้ เพราะต้องมี backend ตรวจรหัส

## คำสั่งบอท (เฉพาะ ADMIN_IDS)
| คำสั่ง | ความหมาย |
|---|---|
| `/gen ST7789` · `/gen ILI9341 3 ร้านA` · `/gen` | สร้างรหัส (ล็อกชิป / จำนวน / โน้ต) |
| `/status รหัส` | ดูสถานะ, เวลา, IP |
| `/list [new\|active\|used]` | 20 รายการล่าสุด |
| `/revoke รหัส` | ยกเลิก |
| `/reset รหัส` | เปิดสิทธิ์ใหม่ (ลูกค้าโหลดพลาด) |

## กติกาของรหัส
- 12 ตัวอักษร (~58 bit) สุ่มด้วย `crypto` · หมดอายุ 7 วันถ้าไม่ใช้ (`CODE_TTL_HOURS`)
- กรอกถูก → เปิดเซสชัน 30 นาที โหลดไฟล์ได้ (ไฟล์ละไม่เกิน 5 ครั้ง กันเน็ตหลุด)
- ติดตั้งสำเร็จ → รหัสถูกเผาทันที · ถ้าหมดเวลาหลังเริ่มโหลดแล้ว → ถือว่าใช้แล้ว · ถ้าหมดเวลาโดยยังไม่ได้โหลดเลย → คืนสิทธิ์
- กรอกผิด 8 ครั้ง/10 นาที ต่อ IP → ถูกบล็อกชั่วคราว
- ไฟล์ firmware ไม่เคยอยู่ใน public/ — เข้าถึงได้ผ่าน token ของเซสชันเท่านั้น

## ข้อจำกัดที่ควรรู้
ลูกค้าที่โหลดไฟล์ได้แล้ว **เก็บ .bin ไว้เองได้** (เบราว์เซอร์ต้องได้รับไฟล์จริงเพื่อเขียนลงบอร์ด) ระบบนี้กัน “แจกลิงก์/ใช้รหัสซ้ำ” ไม่ได้กันการคัดลอกไฟล์หลังโหลด ถ้าต้องกันจริง ๆ ต้องผูกลิขสิทธิ์ในตัวเฟิร์มแวร์ (เช่น license ผูก chip ID)
