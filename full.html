DashTron คืออะไร

เกจวัดดิจิทัลสำหรับรถยนต์และมอเตอร์ไซค์ ใช้เสียบกับ OBD2 ผ่านอะแดปเตอร์ ELM327 แบบ Bluetooth (ชื่อ “OBDII”, PIN 1234) แล้วแสดงค่าจาก ECU แบบเรียลไทม์บนจอสัมผัส

ทำอะไรได้บ้าง

1. เชื่อมต่อและจับรถอัตโนมัติ
  • รองรับทั้งรถยนต์และมอเตอร์ไซค์ ผ่าน OBD2 เหมือนเดิม
  • อ่านและตั้งค่า PID อัตโนมัติ ตรวจว่ารถหรือมอเตอร์ไซค์คันนั้นรองรับค่าใดบ้าง แล้วตั้งค่าที่จะอ่านให้เอง ไม่ต้องตั้งเอง
  • ค้นหาและต่อ ELM327 เอง และจำ MAC ไว้ ครั้งต่อไปต่อเร็วขึ้น
  • ต่อหลุดแล้วลองต่อใหม่เอง
  • อ่านเลข VIN แล้วระบุยี่ห้อให้อัตโนมัติ ไม่ต้องเลือกรถเอง
  • มีโปรไฟล์เฉพาะ Toyota, Isuzu, Ford, Honda
  • รู้จักชื่อยี่ห้ออื่นอีกกว่า 20 ยี่ห้อ เช่น Mitsubishi, Nissan, Mazda, BMW, Mercedes, MG, Hyundai แต่ใช้โปรไฟล์ทั่วไป
  • รองรับโปรโตคอล OBD2 มาตรฐานทั้ง CAN, ISO และ J1850
  • ซ่อนค่าที่รถคันนั้นไม่รองรับให้เอง
2. แสดงค่าเรียลไทม์ 18 ค่า
  • ความเร็ว, รอบเครื่อง, อุณหภูมิน้ำหล่อเย็น, อุณหภูมิไอดี (IAT)
  • MAP, MAF, ตำแหน่งปีกผีเสื้อ (TPS), โหลดเครื่อง
  • แรงดันแบตเตอรี่, องศาจุดระเบิด
  • A/F ratio, O2 sensor, แรงดันรางหัวฉีด
  • บูสต์เทอร์โบ (คำนวณจาก MAP หักด้วยความดันบรรยากาศ), อุณหภูมิไอเสีย (EGT)
  • อัตราสิ้นเปลืองน้ำมัน (L/h)
  • Fuel Trim ระยะสั้นและระยะยาว
  • ตัวเลขเปลี่ยนสีเหลืองหรือแดงเมื่อเกินเกณฑ์เตือน
3. หน้าจอและการใช้งาน
  • หน้าหลัก 2 สไตล์ คือ DashTron และ SmartGauge สลับได้ด้วยปุ่ม UI
  • ธีมสี 6 แบบ: Lime, Cyan, Orange, Red, Magenta, White
  • หน้ารายละเอียดทุกค่า
  • หน้ากราฟ 4 หน้า ปัดซ้ายขวาสลับได้: Engine Performance, Thermal, Airflow, Fuel Rail Pressure
  • ภาษาไทยและอังกฤษ ใช้ฟอนต์ Sarabun ตั้งค่าได้ที่หน้า Settings (ค่าเริ่มต้นเป็นไทย)
  • ปรับความสว่างได้ทั้งแบบ Manual และ Auto (ใช้เซนเซอร์แสง LDR บนบอร์ด)
  • สลับทิศทางจอได้ (ปกติ / กลับหัว 180°)
  • จำค่าที่ตั้งไว้ทั้งหมด ได้แก่ ธีม, UI, ภาษา, ความสว่าง, ทิศจอ
4. วิเคราะห์รถ (Settings → Fault Codes)
  • อ่านรหัสข้อผิดพลาด (DTC) ทั้ง stored และ pending พร้อมสถานะไฟ MIL (ไฟเช็กเครื่อง)
  • มีคำอธิบายรหัสมาตรฐาน P0xxx/P2xxx ประมาณ 100 รหัส เป็นภาษาไทยและอังกฤษ
  • ล้างรหัสได้ (ต้องกดยืนยัน 2 ครั้ง)
  • ดูสถานะความพร้อมของระบบ (Readiness Monitors)
  • ดูเซนเซอร์ที่รถรองรับ, Calibration ID, ชื่อ ECU, โปรโตคอลที่ใช้
5. อัปเดตเฟิร์มแวร์
  • กด Update Software บนจอ แล้วตัวอัปเดตแยก (Updater) จะต่อ WiFi ดาวน์โหลดเวอร์ชันใหม่จาก GitHub พร้อมตรวจ SHA-256 ก่อนติดตั้ง
  • แอพหลักไม่ใช้ WiFi เลย

ทำไม่ได้ / ข้อจำกัด

  • ไม่ใช่ตัวจูนหรือแก้ ECU อ่านค่าอย่างเดียว เขียนหรือแก้ค่าใน ECU ไม่ได้ ที่เขียนได้มีแค่คำสั่งล้างรหัส DTC
  • ต้องมี ELM327 แบบ Bluetooth Classic รุ่น WiFi และ BLE ไม่รองรับ
  • ได้เฉพาะข้อมูล OBD2 มาตรฐาน ไม่อ่านข้อมูลเฉพาะยี่ห้อ เช่น ABS, SRS/Airbag, เกียร์, DPF ลึก ๆ หรือรหัสที่ขึ้นต้น B/C/U และไม่ทำ Bi-directional control
  • คำอธิบายรหัส DTC มีเฉพาะ P0xxx/P2xxx รหัสอื่นจะเห็นเป็นเลขรหัสอย่างเดียว
  • ล้างรหัสได้เฉพาะตอนเครื่องดับ (Key ON) ถ้าเครื่องหมุนอยู่ ECU จะปฏิเสธ
  • บางค่าอาจว่างในบางคัน เพราะขึ้นกับว่า ECU รองรับหรือไม่ เช่น EGT, FRP, Fuel Trim, O2S, AFR, อัตราสิ้นเปลือง Isuzu ดีเซลไม่มี Fuel Trim/AFR/O2S/IGN และ Honda ไม่มี EGT/FRP ส่วน Boost ใช้ได้เมื่อรถอ่าน MAP ได้ (รถไม่เทอร์โบจะได้ค่าติดลบหรือใกล้ 0)
  • ไม่มีการบันทึกข้อมูล (data logging) ไม่มี SD card, export หรือส่งข้อมูลขึ้นคลาวด์ กราฟเก็บแค่ในหน่วยความจำและหายเมื่อปิดเครื่อง
  • ไม่มีหน่วยอิมพีเรียล (km/h, °C, kPa, bar) ส่วน Boost แสดงเป็น psi
  • ไม่มีเตือนด้วยเสียง มีแค่เปลี่ยนสีตัวเลข และเกณฑ์เตือนเป็นค่าคงที่ในเฟิร์มแวร์ ผู้ใช้ปรับเองบนจอไม่ได้
  • ไม่มีหน้า GPS/นำทาง/เล่นเพลง เป็นเกจอย่างเดียว
  • อ่านได้ครั้งละรถ 1 คัน (รถยนต์หรือมอเตอร์ไซค์) / 1 ECU และต้องเสียบ OBD2 ค้างไว้ตลอด
  • ความถี่การอ่านขึ้นกับอะแดปเตอร์ ELM327 คุณภาพต่ำหรือรุ่นปลอมอาจช้า ต่อไม่ติด หรือหลุดบ่อย
  • ภาษา: หน่วยวัด, ชื่อยี่ห้อ, ตัวย่อเช่น VIN/ECU และหน้าจอ “Starting...” ตอนบูตเป็นอังกฤษเสมอ
  • นาฬิกา เป็นตัวจับเวลาตั้งแต่เชื่อมต่อ OBD2 ติด ไม่ใช่เวลาจริง
